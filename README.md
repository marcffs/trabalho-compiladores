# trabalho-compiladores
Trabalho da disciplina de compiladores.
## resumo
Com o auxilio das estruturas e algortimos criados pelo professor Isidro, implementa-se uma linguage para calculadoras simples; operações básicas, variáveis, parênteses e comandos tanto de leitura quanto impressão. As operações e os parênteses estabelecem prioridades e estas são respeitadas pelo compilador.
